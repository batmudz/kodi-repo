# Kodi Repository – Nicole / Mootjuh

Eigen repository voor losse Kodi-addons (o.a. Red Light) zodat je niet steeds de volledige Nicole-build hoeft te downloaden.

## Structuur
- `repository.batmudz/` — de repository-addon
- `addons.xml` + `addons.xml.md5` — index
- `zips/` — hier komen de addon-zips

## In Kodi installeren
1. Zet GitHub Pages aan (Settings → Pages → Branch: main)
2. Download later `repository.batmudz.zip`
3. In Kodi: Add-ons → Install from zip file

Daarna updaten addons via Check for updates.
